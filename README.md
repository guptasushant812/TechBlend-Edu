## ✨ Features

- Course catalog across 6 categories — Programming, Front-End, Backend, Databases, AI & ML, Design & Animation
- 11 individual course pages (HTML, CSS, JS, Python, Java, C, SQL, Statistics, AWS, Azure, ChatGPT)
- About, Team, Instructor, Testimonials, and Contact pages
- Login / Signup UI
- Fully responsive across mobile, tablet, and desktop

## 🛠️ Tech Stack

| Layer | Technology |
|---|---|
| Structure | HTML5 |
| Styling | CSS3, Bootstrap 5 |
| Interactivity | JavaScript |
| Hosting | Netlify |

## 🚀 Quick Start

```bash
git clone https://github.com/guptasushant812/TechBlend-Edu.git
cd TechBlend-Edu
npx serve .
```

No build step, no backend — just open `index.html`.

## 🧭 Known Limitations

- Login/Signup are UI only — not connected to a backend
- Contact form doesn't submit anywhere yet
